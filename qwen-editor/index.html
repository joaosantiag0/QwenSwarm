• Master Server (RTX 3060 12GB): Executa a fila localmente via ComfyUI. Pausar o Master para o worker local sem cancelar a renderização em andamento e sem afetar os satélites.

• Worker Satélite (ex: Notebook Predator 3060 6GB): Requisita blocos de tarefas pendentes via API HTTP. Ao pausar um satélite aqui no painel, ele conclui o bloco atual e não recebe novos itens até ser retomado.

• Resiliência Offline: Se o Master reiniciar ou ficar offline temporariamente, os satélites continuam renderizando em buffer local (outbox/) e entregam os resultados assim que a conexão restabelecer.
